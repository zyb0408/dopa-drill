# Dopa Drill（ドパドリル）

这是一款算术练习游戏：每解出一道题，演出和音乐就会愈发热烈。仅需浏览器即可运行。

吉祥物「Dopa Kichi（ドパキチ，吉祥物）」会搬运你输入的数字，答对时还会为你庆祝。随着题目推进，画面与声音不断增多，最后会变成如同庙会般的热闹场面。即使答错节奏也不会中断，更没有游戏结束。

## 特点

- 小学 1～6 年级共 58 项计算技能（依据学习指导要领）。涵盖加、减、乘、除，竖式的中间输入，小数、分数、比例等
- 「个人水平模式」：从实力检测的结果出发，随着熟练度提升逐步解锁下一项技能
- 按年级模式、练习、复习、技能树界面
- 全部答对即为 100 分。若首次正确率达到 80% 以上，可在带限时的 Extra（加时挑战）中争取超过 100 分的成绩
- 音乐与音效全部使用 Web Audio API 合成（未使用音频文件）
- 支持智能手机的竖屏与 PC。PC 上可用数字键与 Backspace 输入
- 在设置中可调整动效强度。也支持静音
- 所有记录均保存在设备本地（localStorage），不会发送到外部

## 本地运行方式

无需构建。只需将 `app/` 以静态托管方式提供即可运行。

```bash
python3 -m http.server 8000 -d app
```

请在浏览器中打开 `http://localhost:8000/`。由于使用了 ES Modules，直接以 `file://` 打开将无法运行。

## 测试

请使用 Node.js 20 及以上版本运行。

```bash
node --test tests/*.test.mjs
```
